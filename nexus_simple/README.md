# NEXUS (простая версия)

Минимальный агент управления ПК на Windows: без LLM, без базы данных,
без веб-интерфейса. Только Python из стандартной библиотеки.

## Что умеет

- **Открывать приложения** — `открой блокнот`, `открой калькулятор`, `открой chrome`
- **Открывать сайты** — `открой ютуб`, `открой сайт stackoverflow.com` (по умолчанию в Яндекс Браузере, см. ниже)
- **Искать файлы** — `найди файл report.docx`, `найди файл report.docx на диске D`
- **Голосовой ввод** — команда `голос` переключает на распознавание речи вместо клавиатуры (опционально, см. ниже)

## Запуск

Базовая версия требует только Python 3.10+ (стандартная библиотека,
зависимостей нет).

**Вариант 1 — окно с интерфейсом (рекомендуется):**

Дважды кликните файл `Запустить NEXUS.bat` — откроется окно программы
в тёмной теме, без чёрного окна консоли рядом.

Или вручную:
```
pythonw gui.py
```

**Вариант 2 — командная строка (как было раньше):**
```
python main.py
```

Дальше просто вводите команды на русском языке.

## Яндекс Браузер

По умолчанию сайты открываются в Яндекс Браузере, если он установлен в
стандартную папку (`%LOCALAPPDATA%\Yandex\YandexBrowser\...` или Program
Files). Если Яндекс Браузер не найден — используется браузер по
умолчанию в системе.

Чтобы отключить это поведение и всегда открывать сайты в браузере по
умолчанию, откройте `nexus/config.py` и поставьте:

```python
USE_YANDEX_BROWSER = False
```

Если Яндекс Браузер установлен в нестандартную папку — добавьте свой
путь в список `YANDEX_BROWSER_PATHS` в `nexus/tools/web.py`.

## AI-агент (умный режим через Ollama)

По умолчанию NEXUS понимает команды по ключевым словам (быстро,
бесплатно, без интернета — но требует говорить примерно так, как
прописано в `config.py`). Можно подключить локальную AI-модель через
[Ollama](https://ollama.com) — она понимает команды гораздо гибче и
разговорнее, при этом полностью бесплатна и работает прямо на твоём
компьютере (никакие данные никуда не уходят).

**Установка (один раз):**

1. Скачай и установи Ollama с https://ollama.com (Windows-инсталлятор)
2. Открой командную строку и выполни:
   ```
   ollama pull llama3.2
   ```
   Это скачает небольшую модель (~2 ГБ), достаточную для распознавания
   команд. Ollama после установки сама поднимает локальный сервер и
   запускается вместе с Windows — отдельно её запускать не нужно.
3. Всё — NEXUS сам обнаружит Ollama при следующем запуске и начнёт её
   использовать. Если Ollama не установлена или не запущена — NEXUS
   автоматически (и без единой ошибки) использует обычный парсер по
   ключевым словам, как раньше.

**Проверить, что видит NEXUS:**
```
ai статус
```

**Включить/выключить без переустановки:**
```
ai вкл
ai выкл
```

**Если хочешь другую модель** (например, помощнее или полегче для
слабого ПК) — установи её через `ollama pull <имя>` и укажи в
`nexus/config.py`:
```python
OLLAMA_MODEL = "qwen2.5:3b"  # или другая модель из ollama.com/library
```

## Озвучка ответов (текст-в-речь)

NEXUS может отвечать вслух — коротко и быстро, полностью офлайн (без
единого сетевого запроса, специально ради скорости).

**Установка:**
```
pip install pyttsx3
```
(если увидите ошибку про `win32com` — дополнительно `pip install pywin32`)

**Включить/выключить:** галочка «🔊 Озвучка» в окне, либо текстом:
```
звук вкл
звук выкл
```

**Мужской голос.** По умолчанию Windows ставит для русского языка только
женский голос («Ирина»). Чтобы получить мужской:

1. Откройте **Параметры Windows** → **Время и язык** → **Речь**
2. Нажмите **«Добавить голоса»**
3. Найдите и установите **русский** голос (обычно называется «Павел»
   или похоже — Windows сам предложит доступные варианты)
4. Перезапустите NEXUS — он автоматически найдёт новый голос

Проверить, какие голоса видит система:
```
голоса
```
Если нужное имя голоса отличается от «Pavel» — впишите точное имя в
`nexus/config.py`:
```python
TTS_VOICE_HINT = "точное имя голоса из списка"
```

**Почему озвучиваются не все ответы.** Списки файлов, справка и другие
длинные/многострочные ответы не озвучиваются намеренно — слушать длинный
список файлов неудобно и медленно. Озвучиваются только короткие
подтверждения вроде «Открываю: notepad».

## Голосовой режим

По умолчанию не активен, чтобы проект запускался вообще без установки
пакетов. Чтобы включить:

```
pip install -r requirements.txt
```

Затем запустите `python main.py` и введите команду `голос` — NEXUS
начнёт слушать микрофон. Скажите команду вслух так же, как написали бы
её текстом (например «открой блокнот»). Чтобы вернуться к клавиатуре —
скажите «текстовый режим».

Голос распознаётся через бесплатный Google Web Speech API (нужен
интернет). Это подходит для личного использования; ограничение по
количеству запросов в день здесь не документировано публично, так что
для промышленного использования стоит подключить платный speech-to-text
API — это отдельная задача на будущее.

**Если `pip install PyAudio` не устанавливается (частая проблема на
Windows, так как пакет требует компиляции через Microsoft C++ Build
Tools):**

1. Скачайте готовый `.whl`-файл под вашу версию Python с
   https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio (неофициальная,
   но широко используемая площадка со сборками для Windows)
2. Установите его: `pip install путь_до_файла.whl`
3. Затем `pip install SpeechRecognition`

Если зависимости не установлены, NEXUS всё равно запускается и
работает в текстовом режиме — при попытке сказать `голос` просто
покажет подсказку по установке.

## Как это устроено

```
main.py                  — точка входа для текстового режима (консоль)
gui.py                    — точка входа для графического окна (tkinter)
Запустить NEXUS.bat       — двойной клик запускает gui.py без консоли
nexus/
  config.py               — алиасы приложений/сайтов, триггер-фразы команд
  parser.py                — разбирает текст в Intent (action, target, extra)
  tools/
    apps.py                — Tool: открытие приложений (Рабочий стол / Пуск / Store)
    web.py                  — Tool: открытие сайтов (Яндекс Браузер / по умолчанию)
    files.py                — Tool: поиск файлов (os.walk)
    voice.py                — Tool: распознавание речи (опционально)
```

И `main.py`, и `gui.py` используют одну и ту же функцию `dispatch()` из
`main.py` — окно и консоль это просто два разных способа ввода/вывода
поверх одной и той же логики (parser -> tools).

Каждый файл в `tools/` — это отдельный **Tool** с единственной функцией
и понятной ответственностью. `parser.py` играет роль упрощённого
**Planner** — определяет, какой Tool нужен и с какими аргументами.

Это специально сделано так, чтобы структура совпадала с будущей полной
архитектурой NEXUS (Agent Engine + LLM function calling + Permission
System + Task Manager), описанной в основном обсуждении проекта.
Когда будем расширять:

- `parser.py` → заменится на LLM с tool/function calling, но Intent
  как формат "что вызвать и с какими аргументами" останется.
- Каждый Tool получит атрибуты `name`, `description`, `parameters`,
  `permission_level` (READ / SAFE_WRITE / DANGEROUS) для единого
  интерфейса.
- Появится Permission Manager, который будет спрашивать подтверждение
  перед DANGEROUS-действиями (пока таких действий тут нет — все три
  tool'а безопасны: запуск процесса, открытие URL, чтение ФС).

## Ограничения текущей версии

- Понимает только ключевые слова из `config.py` — добавляйте свои
  приложения и сайты в словари `APP_ALIASES` / `SITE_ALIASES`.
- Поиск файлов без указания диска ищет только в Desktop / Documents /
  Downloads / Pictures / Videos пользователя (чтобы не сканировать
  весь диск C по умолчанию).
- Нет истории, нет памяти между запусками, нет веб-интерфейса —
  это следующие этапы.

## Как добавить своё приложение или сайт

Откройте `nexus/config.py` и добавьте пару "ключевое слово": "команда":

```python
APP_ALIASES["обс"] = "obs64"          # если OBS Studio в PATH
SITE_ALIASES["почта яндекс"] = "https://mail.yandex.ru"
```
